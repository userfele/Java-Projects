# Java Projects

A collection of Java programs that I have built during my time in college.

## QuizApp

An object-oriented quiz application that can accept multiple type of questions, such as multiple choice and true/false.

Technologies and concepts used: Object-oriented programming, enums, ArrayLists, encapsulation

How to run: Compile and run QuizApp.java

## PrintCalendar

An object-oriented program that will print a calendar for a given month and year.

Technologies and concepts used: User input, date objects (LocalDate), string formatting

How to run: Compile and run PrintCalendar.java and input the desired month (as a number between 1 and 12) and year.

## SpiralGenerator

A graphical program that will display a spiral in a graphical application window.

Technologies and concepts used: Java Swing, graphics objects

How to run: Compile and run SpiralGenerator.java

## GrazingMammals

An object-oriented program that uses interfaces and classes to model different types of grazing mammals.

Technologies and concepts used: Interfaces, abstract classes, inheritance, polymorphism

How to run: Compile and run GrazingMammals.java
